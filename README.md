# IssueFlow Mobile

A mobile-style GitHub assigned issues app built as a lightweight web app. It runs locally in the browser and can be launched with Vite.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL that Vite prints in the terminal (typically http://localhost:3000).

## Build for production

```bash
npm run build
```

## Notes

- Built as a mobile-first dashboard for viewing assigned GitHub issues.
- Includes demo issue data and a polished dark UI inspired by your provided design.
- Can be adapted later to connect to the GitHub API using a personal access token.
